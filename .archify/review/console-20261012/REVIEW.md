# 控制台优化验收（2026-10-12）

本轮只改控制台与其共用连接层。章节正文、图源、Archify 产物、机制播放器、实验注册表和全站阅读样式没有修改。

## 修复与行为

- 连接设置移出 236px 侧栏；独立控制台样式支持 320 / 390 / 768 / 1024 / 1440 / 1920px 双主题。桌面请求和响应并排；窄屏先编辑、再查看响应和示例。DOM 顺序与窄屏显示顺序一致。
- 预设与历史点击只填入编辑器；课程深链仍自动执行。先切分深链的三个编码段，再独立解码，保留 body 内的 `|`、中文、百分号和换行。损坏链接给出可见说明；保留 Pages 子路径、端点、认证别名和 raw 标记。
- 地址校验与归一化；连接徽章使用本页输入框的目标和凭据，忽略旧检测结果。失败提示使用本次请求目标，不把所有网络失败都断言为 CORS。
- JSON/NDJSON 格式选择、校验与格式化；流式接口按路径识别 Content-Type。发送与 NDJSON 格式化保留末尾换行的存在或缺失；非法 JSON 的 `_search` 请求用 JSON 类型原样交给 ES。保留破坏实验入口。
- GET/HEAD 明确不发送请求体，草稿保留；支持停止、超时设置、重复发送防护、取消后忽略旧响应、快捷键和两空格缩进。
- 响应保留真实原文，提供格式化 / 原文 / 可读取响应头、复制与复制失败时的选中回退、空响应说明和服务端错误摘要。Bulk `errors:true` 显示部分失败，即使 HTTP 为 200。
- 历史形状校验、60 条上限、键盘按钮、端点与格式回填及清空。认证输入框只在内存；UTF-8 Basic 编码保留密码空格。响应高亮对所有文本转义。
- 修正三个示例：search 线程池只查询 search；标准分词不依赖 study 索引；explain 查询词与示例文档匹配。补充创建、搜索和清理的具体前提。

## 实际验证

1. `node tools/check.mjs` PASS：30 个正式章节、575 张实验卡、22 个机制播放器及既有版本/Bulk/深链门禁全绿。
2. `node tools/console-check.mjs --live --report=.archify/review/console-20261012/client-and-es.json`：15/15 PASS。前 11 项为明确的连接层单元测试；后 4 项实际访问本机匿名 9200 / ES 9.4.0 / Lucene 10.4.0。
3. Chrome 154 / macOS 实际运行 `tools/console-browser-check.html`：27/27 PASS，结果见 `browser.json`。包括真实跨域 fetch 的健康 JSON、CAT 文本、HEAD 404 空响应、错误 JSON 的真实 400、Pages 前缀深链与完整含 `|` 的 `_analyze` body；另有示例/历史/格式化/复制回退/快捷键/取消竞态/损坏存储等检查。
4. 六档 iframe 视口、浅深主题，页面无横向溢出，连接字段/请求路径/请求体/面板容纳；路径输入框宽度至少 140px；长响应只在代码块内部横向滚动。浏览器未捕获脚本错误或未处理 Promise。
5. 实际查看 CUA 截图中的桌面浅/深、390px 浅/深连接区、编辑区和错误响应；发现路径栏被发送按钮挤窄后调整 flex-basis，重新通过全部浏览器检查并补看最终 1440px 深色桌面。截图保存在本会话 CUA 工具记录中，仓库保留检查 JSON，未声称有独立 PNG 文件。
6. 真实 ES 对唯一命名的 `tut-console-qa-<timestamp>` 临时索引执行创建、带换行 Bulk 成功、缺换行 400、坏 source 的 HTTP 200 / 条级 400、GET 读回；finally 点名删除并以 HEAD 404 确认。执行后的索引已经清理；没有修改现有 study 或各章索引。

## 范围与限制

- 9201 安全节点未运行，真实安全认证未验收。认证别名、当前地址、UTF-8/空格、内存生命周期和实验自定义认证头经过逻辑检查；9201 网络失败由浏览器实际观察。
- 浏览器的 Bulk 部分失败、超时、取消竞态、剪贴板成功/拒绝使用明确的客户端桩；不属于真实 ES 结果。真正的 Bulk 协议行为另由连接层 live 检查验证。
- 复制的浏览器权限拒绝路径已验证；没有声称操作过用户的系统剪贴板或验证所有浏览器的权限 UI。
- 响应头只显示浏览器允许读取的头；跨域下仍受 ES 的 CORS expose-headers 限制。停止只取消浏览器等待，不能保证撤销已经到达 ES 的操作。
- 本轮不涉及 Archify，未重新执行其原生门禁。`.gitignore` 原有未提交的 `learn-code/` 修改不纳入本次提交。

## 复现

```sh
node tools/console-check.mjs             # 连接层单元测试，不访问真实 ES
node tools/console-check.mjs --live      # 另需 127.0.0.1:9200 的 ES 9.4.0
python3 tools/console-review-server.py   # 仅绑定 127.0.0.1:8766
```

通过 CUA 或手动打开 `http://127.0.0.1:8766/tools/console-browser-check.html`，点击“运行全部检查”。测试临时修改并恢复该本地测试 origin 的主题、端点及历史；报告写入本目录 `browser.json`。该服务也映射 `/es_web/`，以验证 Pages 子路径。生产页面保持静态、零构建、零 CDN。
