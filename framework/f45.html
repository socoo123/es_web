游客带着行动不便的家人去“江岸夜游”，希望行程不超过90分钟，晚上住进有早餐、可取消的无障碍房。运营又刚改了票价、撤下一个景点，搜索却仍显示旧资料。前44课分别练过这些能力；现在要由你决定哪些是硬条件、哪些决定排序，酒店条件是否属于同一报价，更新又停在链路哪一段。本课从独立空资源开始，把景点、酒店、双节点与真实同步接起来，并用一次故障恢复证明结果可信。

2. “完整”是连通职责与证据，不是重测所有课

Elasticsearch在这里提供搜索投影：按条件找候选、排序并返回内容。SQL保留来源事实，酒店逐晚表提供固定快照；搜索结果不承担订单确认或扣库存。投影的含义是把来源整理成适合查询的文档，它可以延迟，也可能保留逻辑删除标记。因此“数据库改了”“消费者到末端”“游客已经看到新价”是三个需要分别证明的事实。

本课的空环境指没有任何F45业务schema、索引、topic和消费位置，可以在保留前课环境的同一台电脑上开始。完整链路选择一条PG景点投影与一份酒店快照来验收；不要求同时启动MySQL，不把中文插件、搜索质量评估、安全、在线重建和容量测量的历史通过记录搬成本课结果。

验收时只有本次实验写入SQL，执行完两笔变更后暂停新的业务写入。我们确认实际event_id、实体与修订号，再将Kafka的固定末端作为本轮H。这个冻结来源边界使SQL与ES可以逐字段比较；它不能证明持续并发来源已实时追平。持续写入下的来源fence、双版本与切换条件仍按F41处理。

固定原始文件与来源SQL

八份景点JSON · 逐晚原表 · 初始导入SQL。SQL列保留业务类型，outbox保存同事务生成的完整不可变文本。

CREATE SCHEMA f45;
CREATE TABLE f45.attractions (
  attraction_id text PRIMARY KEY, name text NOT NULL, city_code text NOT NULL,
  currency text NOT NULL, status text NOT NULL, accessible boolean NOT NULL,
  visit_minutes integer NOT NULL, location jsonb NOT NULL,
  sync_revision bigint NOT NULL, sync_deleted boolean NOT NULL,
  ticket_price_fen bigint NOT NULL
);
CREATE TABLE f45.projection_event (
  event_id bigserial PRIMARY KEY, attraction_id text NOT NULL,
  revision bigint NOT NULL, document text NOT NULL
);
CREATE FUNCTION f45.emit(id text) RETURNS void LANGUAGE sql AS $$
  INSERT INTO f45.projection_event(attraction_id, revision, document)
  SELECT attraction_id, sync_revision, row_to_json(a)::text
  FROM f45.attractions a WHERE attraction_id = id;
$$;
CREATE PUBLICATION f45_publication FOR TABLE f45.projection_event;
GRANT USAGE ON SCHEMA f45 TO f45_cdc;
GRANT SELECT ON f45.projection_event TO f45_cdc;

6. c02：最低价必须来自同一份合格报价

一份酒店文档包含offers数组，能自然保证一酒店只返回一次；每个报价用nested保留自己的属性关联。候选生成先查完整两晚、各晚库存≥1、价格非缺失、最短入住≤2，再用整数分相加。查询仍检查指定日期、币种、容量、无障碍、早餐、可取消和总价。日期相同不代表库存自动成立，这部分证据必须回到原始逐晚表。

inner_hits告诉你哪份offer合格；nested sort必须复用同一完整filter，才会按合格offer的最低总价比较酒店。如果排序省略早餐条件，h02一类酒店的展示价格就可能来自游客根本不能选择的报价。官方nested说明解释了子文档匹配与父文档返回的关系。

    static void consume(ElasticsearchClient es, String mode, long high) throws Exception {
        try (var c = new KafkaConsumer<String,String>(properties())) {
            c.assign(List.of(TP));
            long begin = c.beginningOffsets(List.of(TP)).get(TP), end = c.endOffsets(List.of(TP)).get(TP);
            var saved = c.committed(Set.of(TP)).get(TP);
            if (mode.equals("seed")) {
                check(saved == null && high == begin && begin == 0, "Seed only a fresh group/topic");
                c.commitSync(Map.of(TP, new OffsetAndMetadata(high))); log(Map.of("kind", "seed", "next", high)); return;
            }
            long next = mode.equals("events") ? begin : saved == null ? -1 : saved.offset();
            check(begin <= next && next <= high && high <= end, "Outside retained/committed boundary");
            c.seek(TP, next); long deadline = System.nanoTime() + Duration.ofSeconds(45).toNanos();
            while (next < high) {
                var records = c.poll(Duration.ofMillis(200)).records(TP).stream().filter(r -> r.offset() < high).toList();
                if (!records.isEmpty()) {
                    var docs = new ArrayList<ObjectNode>();
                    for (var r : records) {
                        var row = envelope(r.key(), r.value());
                        var d = document(row.path("document").asString());
                        check(d.path("attraction_id").equals(row.path("attraction_id"))
                            && d.path("sync_revision").asLong() == row.path("revision").asLong(), "Revision/ID mismatch");
                        if (mode.equals("events")) log(Map.of("kind", "event", "offset", r.offset(), "key", r.key(), "value", r.value()));
                        else docs.add(d);
                    }
                    if (!mode.equals("events")) apply(es, docs);
                    next = records.getLast().offset() + 1;
                    // ES can succeed before this commit; the guard makes replay safe.
                    if (!mode.equals("events")) c.commitSync(Map.of(TP, new OffsetAndMetadata(next)));
                }
                check(System.nanoTime() < deadline, "Bounded consumer timed out");
            }
            log(Map.of("kind", mode, "next", next, "high", high));
        }
    }

拼酒店条件、取全局便宜价
