# F02 · 人工推演样本

[xihu.json](xihu.json) 是正文中的一份文档设计样本。[model.json](model.json) 保存五份固定景点、手工词项、查询条件及手工评分规则，便于人工核对。

这些价格、状态、中文分词和分数均为教学设计，不代表真实旅游信息、ES analyzer 输出或 BM25 分数。A–E 是阅读用短标签；拟将 ES `_id` 与业务字段 `attraction_id` 对齐，但本课没有写入 ES。只搜索 `name` / `description`，不搜索别名。金额是整数人民币分，所有样本币种为 CNY。

概念课没有启动、清理或重跑 ES 的步骤。重做推演时先恢复 B 为 8000 分，再按照正文重新列词项、候选、硬条件、顺序；第二案例单独改 B 为 22000 分。实际首搜在 F03 实施并另行验收。作者的模型核对和 HTTP 阅读证据见 [本课验收](../../../docs/framework-review/20261014-f02-model/README.md)。
