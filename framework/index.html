阶段一 · F01–F04

认识 ES，完成第一次搜索

↑

先能用自己的话解释 ES 的价值、数据路径和学习路线，再启动 ES、准备可搜索的景点数据。

  1. F01
    ES 的用途

    Elasticsearch 是什么，我们为什么用它做旅游搜索？

    本课要点

    先看游客需求和目标效果；解释全文检索/筛选/排序/聚合，数据库、Java、ES、网站的职责；给出完整学习路线及无需 ES 的场景。以讲解、读图、判断为主

    原验收标记：可阅读
  2. F02
    数据到结果

    一份景点数据怎样变成搜索结果？

    本课要点

    文档、字段、索引、mapping 的最小模型；用几条样本手工推演分词与倒排、候选与排序、写入与可搜索的差别。节点/分片先留在背景中，不讲底层实现

    原验收标记：可阅读
  3. F03
    本机首搜

    让 ES 在本机运行，并查到第一条景点

    本课要点

    隔离单节点/端口/持久数据；版本与目标索引就绪；最小显式 mapping、固定 ID 写入、refresh、搜索与清理；错误端口/重复资源有恢复步骤

    原验收标记：可阅读 / 实测通过
  4. F04
    字段与导入

    景点信息应该怎样存，才能支持后面的搜索？

    本课要点

    text/keyword、多字段、整数金额/日期/geo_point、状态和单位；显式/动态/strict mapping 与类型边界；固定小语料 Bulk 导入、条级失败和重导入

    原验收标记：可阅读 / 待实测
    真实实验待验收

阶段二 · F05–F12

做出景点搜索服务

↑

网站开始支持关键词、城市、预算、附近、筛选计数、排序与分页。F12 用一批新样本独立完成景点搜索。

  1. F05
    关键词查询

    “西湖”是在找名称，还是精确编码？

    本课要点

    match/term/phrase、查询分析、AND/OR 和词序；先预测命中再解释，分清关键词与精确条件

    原验收标记：可阅读 / 待实测
    真实实验待验收
  2. F06
    组合筛选

    怎样只找杭州、预算内、附近且可游玩的景点？

    本课要点

    bool 的 must/filter/should/must_not、minimum_should_match、range/geo_distance；边界值、缺价、免费与下架反例

    原验收标记：可阅读 / 待实测
    真实实验待验收
  3. F07
    Java 接入

    网站输入怎样真正到达 ES？

    本课要点

    Boot 4/JDK 25、官方 Java API Client、最小搜索接口与配套展示壳；REST↔Java↔卡片一致；客户端生命周期、连接不可用与错误返回

    原验收标记：可阅读 / Java实连
  4. F08
    多字段与高亮

    名称、别名和描述怎样一起搜，结果怎样让人看懂？

    本课要点

    multi_match/copy_to、字段分工与高亮；“描述提到西湖”与“景点就是西湖”对照；DTO、命中 ID 和安全高亮返回

    原验收标记：可阅读 / 多字段实连
  5. F09
    聚合计数

    筛选栏的数量为什么常常算错？

    本课要点

    terms/range/filter 聚合、query/post_filter、同维多选/跨维条件；统计范围、文档数与候选误差

    原验收标记：可阅读 / 聚合实连
  6. F10
    显式排序

    价格、距离和默认相关性，应该按哪把尺子排序？

    本课要点

    显式 sort、缺值、单位、稳定第二键、track_scores；三个排序模式的结果对照，不把评分与价格混为一谈

    原验收标记：正文 / 真实排序
  7. F11
    稳定分页

    翻到下一页，为什么会重复或漏掉景点？

    本课要点

    from/size 的范围与成本、search_after、PIT 搜索视图、完整 sort；并发变更、游标关闭/过期与条件改变

    原验收标记：可阅读 · 含实验
  8. F12
    更新与冲突

    改价、下架与同时修改之后，搜索结果怎样才算正确？

    本课要点

    固定 ID CRUD、局部更新/删除；受控 refresh 下 GET/search；seq_no/primary_term 冲突与重读；用新样本独立验收景点服务

    原验收标记：可阅读 · 含结业任务
    结业实践

阶段三 · F13–F17

让中文搜索找得准

↑

同一批查询对照分词、别名、同义词与提示效果：既找出漏掉的结果，也检查新增的错误匹配。

  1. F13
    分析链

    明明有“北京故宫博物院”，为什么搜不到？

    本课要点

    _analyze、token/position/offset、tokenizer/filter、索引/搜索 analyzer；标点、大小写、中英混合

    原验收标记：可阅读
  2. F14
    中文分词

    不同中文分词器切出来的词，真的适合旅游吗？

    本课要点

    内置基线与 standard/SmartCN/ICU/IK 候选同语料对照；制品兼容、安装/重启、中文歧义、漏/误召回，不按名气选插件

    原验收标记：可阅读
  3. F15
    词典与重建

    新酒店品牌和地名怎样进入搜索词典？

    本课要点

    专有词、词典生效方式、旧 token 不自动改变、必要重建；新词召回改善与新增误匹配

    原验收标记：可阅读
  4. F16
    别名与同义词

    “紫禁城”和“故宫”怎样找到同一景点？

    本课要点

    别名字段、synonym_graph、多词同义词、分析链顺序、繁简；同名景点仍需城市消歧

    原验收标记：可阅读
  5. F17
    提示与容错

    输入一半、拼音或错字时，提示应该怎样给？

    本课要点

    completion/search_as_you_type 候选、拼音辅助字段、fuzzy；去重、下架排除、短词误扩展与适用边界

    原验收标记：可阅读

阶段四 · F18–F22

让好结果排在前面

↑

比较名称、点评、热度、距离等规则怎样改变名次。F22 用留出查询检验改善与退步。

  1. F18
    BM25 评分

    ES 的相关性分数究竟在衡量什么？

    本课要点

    BM25/_explain、词频/文档频率/字段长度、评分与过滤；固定语料/分片，比较相对次序，不背公式代替解释

    原验收标记：可阅读
  2. F19
    多字段权重

    怎样让名称真正命中，胜过描述中的顺带提及？

    本课要点

    boost、短语、多字段、dis_max、should/minimum_should_match；名称/描述重复命中和权重过大反例

    原验收标记：可阅读
  3. F20
    质量与热度

    热门与好评能加分，为什么不能一味加？

    本课要点

    function_score/field_value_factor/rank_feature 候选、缺值/尺度/封顶；5 分一条点评、极高热度弱相关的反例

    原验收标记：可阅读
  4. F21
    距离与时效

    附近、新鲜、便宜，与相关性怎样取舍？

    本课要点

    距离/时效衰减、score_mode/boost_mode；默认排序与用户指定 sort；先满足硬条件再谈加分

    原验收标记：可阅读
  5. F22
    搜索质量评估

    调了权重，怎样证明搜索真的变好了？

    本课要点

    查询集、相关性标注、留出集、Recall@10/nDCG@10、坏案例回归；基线/改造对照，报告得失与适用范围

    原验收标记：可阅读
    结业实践

阶段五 · F23–F27

处理酒店与房型搜索

↑

从景点进入酒店与房型，核对同房型条件、匹配最低价和逐晚总价，解释搜索候选的边界。

  1. F23
    文档边界

    一个酒店、多个房型，到底该建成几份文档？

    本课要点

    酒店主文档、nested 房型、独立 offer；查询能力、数据规模与更新代价，多价目计划/币种/状态边界

    原验收标记：可阅读
  2. F24
    同房型条件

    “便宜”和“含早”为什么不能分别来自两个房型？

    本课要点

    object 串条件反例、nested query、inner_hits、nested sort filter；人数/床型/早餐/退改/预算统一条件

    原验收标记：可阅读
  3. F25
    多晚库存

    连住两晚，怎样知道每晚都有房、总价是多少？

    本课要点

    [入住,离店)、逐晚覆盖/库存；ES 候选与 Java 固定价表核对；缺一晚/售罄/最短入住，快照边界

    原验收标记：可阅读
  4. F26
    去重与最低价

    酒店列表的“最低价”究竟是哪一种价格？

    本课要点

    collapse/inner_hits、酒店数与 offer 数、合格房型最低价/起价/入住总价；Top K 复核与完整集合精确排序差别

    原验收标记：可阅读
  5. F27
    分层排序

    酒店与房型各自怎样排序才符合用户意图？

    本课要点

    酒店相关性/品质/距离，房型总价/偏好；稳定次序、缺价/旧库存复核、排序覆盖范围

    原验收标记：可阅读

阶段六 · F28–F35

让搜索服务持续运行

↑

将相同查询放到多节点上，观察停节点、索引升级、备份恢复与权限配置的实际结果。

  1. F28
    多节点集群

    一台机器变三台，怎样知道它们组成了同一个集群？

    本课要点

    隔离多节点配置、发现、首启引导/已有集群重启、持久目录、master/data/ingest/协调职责；核对 UUID/角色/主副布局

    原验收标记：可阅读
  2. F29
    分片与路由

    一份景点文档写到哪里，搜索又从哪里读？

    本课要点

    主分片/副本、_id/自定义 routing、正确写读查路由、搜索分发；错误 routing 选取跨片样本，不假设每次都落错片

    原验收标记：可阅读
  3. F30
    选主与恢复

    主节点或数据节点停了，搜索系统分别会怎样？

    本课要点

    区分 master 选举与数据主分片提升；投票多数、失去多数、目标分片副本/全部副本不可用、节点回归恢复；两类故障分别观察

    原验收标记：可阅读
  4. F31
    分配与扩缩容

    加机器为什么未必解决未分配与容量问题？

    本课要点

    allocation explain、节点/磁盘约束、迁移、排空缩容；split/shrink/reindex 条件，不以集群颜色代替数据核对

    原验收标记：可阅读
  5. F32
    模板与别名

    后端怎样不再写死具体索引名？

    本课要点

    composable template、优先级/模拟/新索引继承，版本索引、读写 alias/is_write_index；错误配置与修复

    原验收标记：可阅读
  6. F33
    索引升级

    字段或分词变了，怎样升级索引而不中断查询入口？

    本课要点

    固定快照/受控暂停写入 reindex、新旧核对、原子 alias 切换/回滚；迁移不自动跟随后续变化

    原验收标记：可阅读
  7. F34
    备份与恢复

    副本都有了，为什么还必须练习备份恢复？

    本课要点

    隔离仓库、snapshot 状态、restore 到隔离资源、计数/字段/代表查询；副本与备份的不同用途

    原验收标记：可阅读
  8. F35
    安全与权限

    旅游搜索接口需要哪些 ES 权限？

    本课要点

    TLS、认证、API key/角色、Java 连接；只读/受限写入、401/403、凭据管理；学习配置与部署条件区别

    原验收标记：可阅读

阶段七 · F36–F42

让搜索跟上业务变化

↑

在数据库改价、下架与删除，沿事件、Java 投影和 ES 跟踪变化，验证积压、重放与对账。

  1. F36
    搜索投影

    数据库的表，为什么不能简单搬成一个个索引？

    本课要点

    最小业务表、搜索文档投影、业务 ID、快照与增量衔接；DB→事件→Java→ES 写入→搜索可见各阶段

    原验收标记：可阅读
  2. F37
    PostgreSQL 同步

    PostgreSQL 的一次增删改，怎样进入 ES？

    本课要点

    WAL→Debezium→Kafka→最小单表 Java 消费→ES；pgoutput/publication/slot、主键/删除信息；事件/位置/搜索结果核对、重启恢复与 WAL 保留

    原验收标记：可阅读
  3. F38
    MySQL 同步

    换成 MySQL，哪些同步条件和恢复证据不同？

    本课要点

    binlog ROW、快照/streaming、schema history/位置、权限；复用最小 Java→ES 链路，独立 profile 复现同一组变更，与 PG 对照

    原验收标记：可阅读
  4. F39
    多表投影

    一个标签或房型改了，怎样更新正确的搜索文档？

    本课要点

    Java 事件路由、受影响实体、关联旧新 ID、组装/Bulk；上下架/删除传播、多表投影，不机械一表一索引

    原验收标记：可阅读
  5. F40
    重放与乱序

    消息重复、乱序和部分写入失败，怎样避免旧数据复活？

    本课要点

    幂等/版本/删除保护、条级失败、重试/DLQ、429/不可用、offset 时机、失败重放；不把跨分区 offset 当全局版本

    原验收标记：可阅读
  6. F41
    重建与追平

    网站持续改价时，索引重建怎样追平再切换？

    本课要点

    与 F33 区分；全量/增量、删除、检查点、双版本投影、alias 切换/回滚，旧事件不能覆盖新状态

    原验收标记：可阅读
  7. F42
    延迟与对账

    显示了旧价格，怎样知道延迟在哪、数据是否丢了？

    本课要点

    DB/消息/写入/搜索可见延迟、条数/字段/删除对账、补偿与复验；收到消息不等于结果正确

    原验收标记：可阅读

阶段八 · F43–F45

独立实现，带着问题读源码

↑

测量容量，按证据诊断故障；F45 从空环境完成新增需求，再带着机制问题进入源码篇。

  1. F43
    负载与容量

    数据和请求变多之后，怎样测量系统还能承受多少？

    本课要点

    可复现语料、Bulk 批次/并发、查询+更新负载、分片/节点布局；吞吐、延迟分位数、拒绝、资源与测量限制

    原验收标记：可阅读
  2. F44
    故障诊断

    搜索慢了或失败了，怎样沿证据找到原因？

    本课要点

    profile/慢日志/hot threads/tasks/统计；source/高亮/聚合/分页/扇出成本、doc values/缓存；熔断/背压/积压、运行配置的受控故障与恢复，按症状选择工具

    原验收标记：可阅读
  3. F45
    独立复现

    不看逐步答案，你能独立完成一个新搜索需求吗？

    原验收标记：可阅读
