## 不适用与未实施

本轮没有运行 ES、Java、插件、多节点、数据库、Kafka、CDC 或本机展示壳，没有生成/修改图源或 SVG；这些项目待相应课次实际交付时分别验收。旧 F01 的三案例两轮实测属于原历史范围，新 F03 迁移后必须重新验收。

复核命令（`python` 需已安装 Playwright 并具备 Chromium）：

```bash
python docs/framework-review/20261014-curriculum/review.py
node tools/check.mjs
git diff --check
```

重新运行会覆盖本目录的自动记录与截图，并将 `visual_review` 设回待审阅；必须重新查看最终截图，才能恢复实际审阅结论。
